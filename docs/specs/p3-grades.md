## 1. Проблема и цель

В v4 `/grades` подключает семестры, дисциплины, сводку, сессию и карточку дисциплины на готовых серверных выборках. Серверные контракты сохранены; реализация интерфейса не означает закрытия критериев приёмки.

**Готово, если:** студент видит семестры, дисциплины, оценки, задолженности, предстоящие экзамены и прошлый семестр; сводка объясняет состояние учёбы без ручного пересчёта.

### Состояние реализации v4 на 21.11.2026

## 2. Границы

**Входит:** seed оценок/экзаменов для двух студентов, тесты изоляции и границ, интерфейс семестров, дисциплин, сессии, сводки и карточки дисциплины.

**Не входит:** изменение модели `Semester`/`Grade`/`Exam` и формул сводки; экспорт документов; редактирование оценок студентом; ИИ-помощник. Контракт ADR 0003 не пересматривается.

## 3. Контракт данных (существующий)

| Функция / тип                                    | Файл                               | Что отдаёт                                                                                          |
| ------------------------------------------------ | ---------------------------------- | --------------------------------------------------------------------------------------------------- |
| `getSemesters(userId, now?)`                     | `src/lib/domain/grades.ts`         | `Semester[]` от нового к старому, `isCurrent` по датам                                              |
| `getSemesterOverview(userId, semesterId?, now?)` | там же                             | `SemesterOverview \| null`: семестр, `grades`, `session`, `summary`                                 |
| `buildGradesSummary(input)`                      | `src/lib/domain/grades-summary.ts` | `GradesSummary`: средний балл, зачётные единицы, задолженности, текст, состояние `NO_DATA/OK/DEBTS` |
| `Semester`                                       | `grades.ts`                        | `id`, `academicYear`, `term`, `startsAt`, `endsAt`, `isCurrent`                                     |
| `GradeEntry`                                     | там же                             | дисциплина, преподаватель, форма контроля, зачётные единицы, балл, статус                           |
| `SessionExam`                                    | там же                             | дисциплина, форма контроля, время, аудитория, преподаватель, результат                              |

`userId` — только из сессии. Чужой `semesterId` даёт пустой результат, несуществующий — `null`; чужие оценки не читаются. Даты — Москва, подписи — `ru-RU`.

## 4. Seed и данные

`P3-BE-04` дополняет `prisma/seed.ts`:

- два студента с заметно разными результатами: у одного есть задолженность, у другого — ровная учёба;
- текущий и прошлый семестр; прошлый — только для чтения;
- дисциплины с разными формами контроля (экзамен, зачёт, дифференцированный зачёт, курсовая);
- оценки по пятибалльной шкале и статусы «зачёт / незачёт / не выставлено»;
- сессия группы: предстоящие и прошедшие экзамены с датой, временем, аудиторией, преподавателем; результат — из `Grade`, если внесён;
- повторный seed не создаёт дублей и не ломает расписание.

Все имена, оценки и номера вымышлены. Демо-аккаунты и пароли — только в `README.md`, не в seed-комментариях.

## 5. Поведение интерфейса

### 5.1. Экраны и блоки

| Экран / блок        | Что показывает                                                                                             | Действия                            |
| ------------------- | ---------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| `/grades`           | переключатель семестров, список дисциплин, оценки текстом и цветом, форма контроля, зачётные единицы       | выбрать семестр, открыть дисциплину |
| Вкладка «Сессия»    | предстоящие и прошедшие экзамены/зачёты: дата, время, аудитория, преподаватель, результат                  | открыть карточку экзамена           |
| Сводная карточка    | средний балл (если применимо), задолженности, ближайший контроль, состояние «в норме / есть задолженности» | перейти к проблемной дисциплине     |
| Карточка дисциплины | форма контроля, преподаватель, оценка, зачётные единицы, связанные занятия                                 | вернуться к списку                  |
| История             | прошлые семестры только для чтения                                                                         | переключить семестр                 |

График Recharts — опционально: если включён, только для успеваемости и со текстовой альтернативой; без графика сводка остаётся понятной.

### 5.2. Состояния

| Состояние        | Где                | Что видит студент                                                  | Что можно сделать |
| ---------------- | ------------------ | ------------------------------------------------------------------ | ----------------- |
| Загрузка         | страница, сессия   | скелетон                                                           | —                 |
| Пусто            | семестр без данных | объяснение и возврат к текущему семестру (`Ф-03.8`)                | вернуться         |
| Ошибка           | страница, карточка | нейтральное сообщение и «Повторить»; выбранный семестр не теряется | повторить         |
| Успех            | после переключения | данные семестра и сводка                                           | —                 |
| Частичная ошибка | сессия/сводка      | остальной экран работает                                           | обновить блок     |

### 5.3. Мобильный опыт и доступность

- 360 px: дисциплины — список карточек, не таблица; длинные названия переносятся, не обрезаются; сессия — список.
- 390/768/1280 px: таблица/сетка с теми же данными; сводка — отдельный блок.
- Оценки и статусы дублируются текстом, не только цветом; статус «не выставлено» явный.
- Клавиатура: переключатель семестров, вкладки и карточки доступны, фокус видим.
- `prefers-reduced-motion`: анимации переключения отключаются.

## 6. Критерии приёмки

- [ ] `US-04`: сводка, дисциплины, проблемная дисциплина и прошлый семестр доступны без ручного пересчёта.
- [ ] `US-05`: вкладка «Сессия» показывает даты, время, аудитории и преподавателей; результаты — если внесены.
- [ ] `A-04`: оценки, задолженности и предстоящие испытания понятны без пояснений.
- [ ] `A-08`: на 360 px нет горизонтальной прокрутки, длинные названия не обрезаются.
- [ ] `A-09`: загрузка, пусто, ошибка и успех предусмотрены.
- [ ] Студент A не видит оценки и сессию студента B; чужой `semesterId` не раскрывает данные.
- [ ] Прошлый семестр доступен только для чтения; данные сохраняются после перезагрузки.

## 8. Зависимости и риски

- Зависит от `P3-BE-01`–`P3-BE-03` (готово), `P0-FE-01` (компоненты).
- Блокирует `P6-FE-01` (сводка учёбы), `P7-QA-01/02`.
- Риски: seed без оценок оставляет экран пустым; разные определения задолженности в UI и сводке; переполнение длинных названий; график без текстовой альтернативы.
- Если `P3-BE-04` задерживается, UI собирается на тестовых фикстурах, но `P3-GATE-01` не закрывается.
