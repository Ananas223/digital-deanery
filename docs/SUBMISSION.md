## Чек-лист развёртывания (заблокирован человеком)

В окружении нет хостинга и credentials, поэтому деплой не выполнялся и не имитировался. Точная последовательность для человека:

1. Создать PostgreSQL 16 и базу; задать `DATABASE_URL` (серверная переменная, без `NEXT_PUBLIC_`).
2. Задать `BETTER_AUTH_SECRET` (32+ байта), `BETTER_AUTH_URL` и `NEXT_PUBLIC_APP_URL` — публичный HTTPS-адрес приложения.
3. Задать `AI_ASSISTANT_ENABLED=false` для первого запуска; при включении — `AI_PROVIDER_API_KEY` и `AI_MODEL` только на сервере.
4. Выполнить `npm ci`, `npm run db:deploy`, `npm run db:seed`.
5. Собрать и запустить: `npm run build`, `npm start` (Node 22).
6. Проверить `curl -I https://<host>/login`: CSP, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, HSTS, отсутствие `X-Powered-By`.
7. Войти под двумя студентами и сотрудником, проверить сохранение заявки после перезагрузки, недоступность чужой заявки по прямому адресу и отсутствие горизонтальной прокрутки на 360 px.
8. Проверить, что `.env` не попал в репозиторий и в клиентский бандл; ключ провайдера не виден в Network.
