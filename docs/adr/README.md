## Правила ведения

- Новое решение — новый файл `NNNN-тема.md`: четыре цифры номера, короткая тема латиницей через дефис. Следующий номер — 0006.
- Структура файла: контекст → рассмотренные варианты → принятое решение → последствия. Ссылки на PRD, план и `AGENTS.md` даются по ID, без пересказа требований.
- Статусы: «Предложено», «Принято», «Заменено». Заменённое решение не удаляется: в нём указывается, какой ADR его заменил, а в индексе меняется статус.
- Мажорные обновления Prisma, Better Auth, Next.js, React, Base UI и Vercel AI SDK выполняются только через ADR с проверкой совместимости и полным прогоном тестов (`AGENTS.md` § 3.6).
- Изменение принятого решения оформляется новым ADR или явной правкой с записью в истории; молчаливая смена контракта запрещена.
- ADR — часть пакета доказательств: дата, контекст и последствия должны позволять восстановить ход мысли без переписки.
