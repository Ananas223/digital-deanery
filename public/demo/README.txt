Аккаунты создаются `prisma/seed.ts` идемпотентно: повторный запуск обновляет данные, но не дублирует пользователей. Пароли хешируются Better Auth.

Сбросить демо-данные к исходному состоянию:

```bash
npm run db:reset
```

Команда пересоздаёт схему и заново выполняет seed. Она **удаляет все данные** в базе из `DATABASE_URL` — не запускайте её на базе, которую нужно сохранить.
